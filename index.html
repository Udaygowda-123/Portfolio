Under the hood

The API change I'm most pleased with. Independent MongoDB queries were being awaited one after another — nothing depended on the result before it, so every request paid the full sum of the wait. Firing them together with Promise.all means a request now costs roughly the slowest single query instead.

GET /api/dashboard
Before — sequential awaits0 ms
After — Promise.all0 ms

Illustrative timings to show the shape of the change — the queries are independent, so the total collapses from their sum to their maximum.

controllers/dashboard.js
// before — each query waits on the one above it
const user     = await User.findById(id);
const sessions = await Session.find({ user: id });
const scores   = await Score.find({ user: id });
const streaks  = await Streak.find({ user: id });

// after — nothing depends on the last, so fire together
const [user, sessions, scores, streaks] =
  await Promise.all([
    User.findById(id),
    Session.find({ user: id }),
    Score.find({ user: id }),
    Streak.find({ user: id }),
  ]);
